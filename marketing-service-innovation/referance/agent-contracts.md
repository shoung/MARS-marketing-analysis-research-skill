# 子代理任務契約與調度

主代理只編排與驗收；每個子代理只寫自己被分配的檔案，避免同檔競寫。派工時提供：目標、輸入檔與版本、範圍、可寫路徑、來源標準、交付格式、完成條件及未知項。使用環境原生的spawn/followup/send/wait工具，不假定某工具名稱必定存在。

## 任務分工

| 任務 | 必要輸入 | 必交結果 |
|---|---|---|
| R1 企業／事件研究 | 已確認brief、查核截止日與地區 | 公司背景、時間線、政策適用條件、事實／來源表、爭議與反證 |
| R2 顧客與體驗研究 | brief、R1已確認主張；可先獨立蒐集顧客線索 | 分群理由、假設或實證Persona、Journey含至少兩組以白話命名的痛點與改善機會、待驗證問題 |
| R3 理論與方案研究 | brief、課堂要求、可用事實 | 理論來源與適用性、至少3方案、評選矩陣、權重理由與敏感度 |
| W 內容整合／修訂 | R1–R3、前輪評審（修訂時） | 六步HTML報告內容稿、Blueprint與試點、逐頁大綱、pitch、AI紀錄草稿；矛盾清單 |
| C1 Kotler視角審查 | 同版完整HTML報告內容稿及簡報內容包、評審規準 | 四分、依據、平均、硬缺失、退修項；不寫作者內容 |
| C2 Parasuraman視角審查 | 同C1，不給C1分數 | 同C1；使用獨立任務上下文 |
| P 成品製作 | 文字Gate通過版、實際專家評語、輸出契約、PPT Master與HTML適配 | 可編輯PPTX、自含HTML、既定TXT及PDF；設計規格、render與製作紀錄另存internal |
| Q 獨立成品QA | 實際成品與來源、輸出契約、評審規準 | 結構／內容／視覺／時間檢查、美學四分、問題位置、證據與判定 |

## 容量與相依

若同時有3個worker席位：先R1/R2/R3，再W，再C1/C2，通過後P，最後Q。R2/R3可預查但須等R1確認政策才定稿。若只有1個席位，依序做各任務，不省略角色；可釋放已完成代理再建立新獨立評審。不能把「依序分工」記成「實際並行」。主代理可請研究者交互核對證據，不讓兩代理同時改同一檔。

C1/C2不得為本版內容作者，Q不得為本版成品製作者；若先前研究代理轉任評審，必須揭露其參與而非稱完全獨立，並優先另派未參與作者角色的新代理。工具或席位實際無法滿足獨立性時，狀態標「受阻」，原因註明「待獨立審查」。單一席位可依序完成時屬正常排程，不因席位少就標受阻。

## 可直接使用的派工骨架

「你負責【角色】。輸入為【檔案／版本】；只寫【路徑】。依本Skill的【相關規範】完成【交付】。逐項區分已查證事實、推論、假設與目標；提供可追溯來源。不得捏造學生訪談或人工確認。完成後回傳檔案、主要發現、限制與下一階段需處理事項。若缺輸入，列出依賴，不以猜測填成事實。」

評審另加：「採【具名學者】的公開理論視角進行AI模擬審查，不冒稱本人。對四項各評0–100並引用頁／段；評分由證據決定。你不是作者，不直接潤飾後替自己打分。不要看另一評審分數。」

QA另加：「先讀實際檔案、PPTX每頁渲染與HTML瀏覽器／列印渲染，檢查比對文字核准版及專家原始評語。按輸出契約列每項pass/fail/not checked與依據；美學四分另算。只開ZIP或抽XML不能聲稱已視覺驗收。」

## 狀態紀錄

正式案例開始前，於internal建立run manifest：規範版本與各檔SHA-256、規範定稿時間、案例開始時間、brief、使用的preflight素材及重新核對範圍。每個任務留代理ID、起迄狀態、輸入版本、輸出檔與限制。狀態只用待輸入／執行中／待修訂／通過／受阻。主代理彙報不偷渡未完成工作，來源或政策改變時標記受影響產物與需重跑的階段。


狀態分三欄，不能互相代替：任務狀態用待輸入／執行中／待修訂／通過／受阻；Gate狀態用未審／未通過／通過；檢核項用pass／fail／not checked。原因寫在附註（例如視覺未驗證、待獨立審查）。必要檢核有fail或not checked時，該Gate不得通過；學生真人排練與目標PowerPoint實機為另列狀態，依輸出契約處理，不冒充已完成。

對外投影片、HTML、備註及講稿不包含本契約的任務代碼、狀態或工具追蹤。以完整方案名與商務短語取代評分、顧客、痛點及來源代稱。內容作者與評審須用一句白話回答使用者的策略問題，逐項核對關鍵行動是否直接處理其指定原因。AI使用紀錄與解題過程採平實學習敘述。QA還須檢查內部元資料未混入成品；原始評審忠實摘編為商業評論，不整份貼入HTML。

內容整合與QA須確認「AI 使用記錄與反思點.txt」以老師六項作為整份文件的六個主標題，不採每事件六欄或代理流水帳；檔名及章節依輸出契約，反思置於相關節。
